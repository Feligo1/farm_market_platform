# Farm Market Platform - User Manual

## For Farmers

### USSD Access
1. Dial *384*# (or your USSD code)
2. Select option 1 for current prices
3. Choose your commodity (Maize, Tomatoes, etc.)
4. View current market prices

### SMS Alerts
To subscribe to price alerts:
Send SMS: SUBSCRIBE MAIZE to 45678

### Web Dashboard
1. Visit https://farmmarket.zm
2. Login with your phone number
3. View real-time prices and forecasts

## For Traders

### Price Submission
1. Login to web dashboard
2. Click "Add Price" in navigation
3. Enter market, commodity, price
4. Submit for verification

## Mobile Access
- Basic phones: USSD or SMS
- Smartphones: Mobile web browser
- Feature: Responsive design works on all devices

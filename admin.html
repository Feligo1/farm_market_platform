Historical data sources

Import real observations only when date, named commodity, market, unit, currency and source are confirmed. FEWS NET publishes historical market-price data; not every product, market or unit is directly compatible with FarmConnect.

FEWS NET price API · FEWS NET market data

To add a sourced observation, choose Price history → Add record, select commodity and market, enter the original date, record the original source, then verify the evidence before publishing.

Import CSV from other sources
